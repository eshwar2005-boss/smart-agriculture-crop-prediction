# Project checklist

- [ ] Download the official Kaggle CSV and place it in `data/Crop_recommendation.csv`.
- [ ] Install dependencies from `requirements.txt`.
- [ ] Run `python src/train_model.py` and review the generated accuracy/report/charts.
- [ ] Run `streamlit run app.py` and test several input combinations.
- [ ] Update this README with the actual measured test accuracy after training.
- [ ] If your guide requires soil-moisture sensor readings, collect a compatible dataset or sensor data and extend the features/model; the standard crop dataset does not contain soil moisture.
- [ ] Connect GitHub and create/push the repository. Do not upload secrets or credentials.
